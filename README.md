# SPAM-EMAIL-CLASSIFIER

A simple Python project that checks whether an email message is spam or safe using predefined spam keywords.

## Features
- Detects spam emails
- Checks for spam keywords
- Displays spam or safe result
- Counts spam words
- Beginner-friendly Python project
- Menu-driven program

## Technologies Used
- Python

## How It Works
1. User selects email check option
2. User enters sender name
3. User enters email message
4. Program checks spam keywords
5. Result is displayed as:
   - Spam Email
   - Safe Email
